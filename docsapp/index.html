Frequently asked questions

Does DocsApp need internet?

No. DocsApp runs entirely offline on your Windows PC using local Ollama models. Your files, embeddings, and conversations stay on your machine — no cloud, no internet required.

What file types are supported?

PDF, Word (DOCX), Excel (XLSX), CSV, plain text, markdown, and images. Scanned PDFs and images are processed with Tesseract OCR when installed. Excel and CSV data can also be used for charts and analysis.

What do I need to run DocsApp?

Windows 10 or 11, Python 3.10+, and Ollama with the recommended models. Optional Tesseract for OCR. No GPU or Docker required — CPU-only setup.

Does it support Greek documents?

Yes. The chat UI supports Greek and English, and Tesseract OCR handles Greek and English scanned documents. The interface includes Greek labels for folders and history.

Συχνές ερωτήσεις

Χρειάζεται internet το DocsApp;

Όχι. Το DocsApp τρέχει εξ ολοκλήρου offline στον Windows PC σας με τοπικά μοντέλα Ollama. Τα αρχεία, embeddings και συνομιλίες μένουν στον υπολογιστή — χωρίς cloud, χωρίς internet.

Ποιους τύπους αρχείων υποστηρίζει;

PDF, Word (DOCX), Excel (XLSX), CSV, απλό κείμενο, markdown και εικόνες. Σαρωμένα PDF και εικόνες επεξεργάζονται με Tesseract OCR όταν είναι εγκατεστημένο. Δεδομένα Excel και CSV μπορούν επίσης να χρησιμοποιηθούν για γραφικές και ανάλυση.

Τι χρειάζομαι για να τρέξω το DocsApp;

Windows 10 ή 11, Python 3.10+ και Ollama με τα προτεινόμενα μοντέλα. Προαιρετικά Tesseract για OCR. Χωρίς GPU ή Docker — CPU-only setup.

Υποστηρίζει ελληνικά έγγραφα;

Ναι. Το chat UI υποστηρίζει ελληνικά και αγγλικά, και το Tesseract OCR χειρίζεται σαρωμένα έγγραφα στα δύο idioms. Η διεπαφή περιλαμβάνει ελληνικές ετικέτες για φακέλους και ιστορικό.
